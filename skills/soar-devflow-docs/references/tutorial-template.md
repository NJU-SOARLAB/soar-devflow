# 教程页（`guide/`）7 段式写作模板

适用于操作员、新加入的工程师或首次上手该能力的使用者。回答：**“我要完成任务 X，具体怎么一步步做？”**

## 推荐结构

1. **开篇导语（1 段）**：直说本页教什么、面向谁、前置条件或当前支持范围。
2. **你将学会**：2–4 条可检验的具体能力，不写空泛口号。
3. **开始之前 `{#prerequisites}`**：版本、依赖、测试数据、设备或权限前提。
4. **界面 / 入口速览**：一张带编号标注的截图（或清晰流程图）+ 编号对照表（`编号 → 控件/命令 → 作用`）。
5. **分步操作 `{#steps}`**：
   - 使用编号步骤；
   - 每步写明**点哪里 / 执行什么命令 / 输入什么**；
   - 每步给出**预期结果**（截图、典型输出或可观察状态）。
6. **进阶与取舍**：常用模式切换、参数取舍、快捷键或性能提示。
7. **出了问题怎么办 `{#troubleshooting}`**：按 `现象 → 可能原因 → 处理方法` 列表格。
8. **原理与相关说明**：链接到对应的 `reference/` 原理说明页与相关教程页。

## 质量基线

- 面向成熟项目建议中文正文 3000–8000 字（具体硬门槛可在 `.soar-devflow/docs.json` 的 `quality.min_chars` 调整）。
- 至少包含 1 张真实截图或清晰示意图；含 UI 操作的教程建议 ≥3 张截图，其中至少 1 张带编号标注。
- 所有命令、按钮文案与配置字段须与当前源码核对一致；双语站点中若界面仅单语，英文页保留原文并加英文意译（如 “开始运行” (*Start run*)）。
