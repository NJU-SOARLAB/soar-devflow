# 交互式初始化访谈问题清单

Agent 在为用户配置 SOAR DevFlow 时，按需裁剪以下问题，尽量在 1–2 轮内问清，不要逐题刷屏。

## 第一组：工作流范围与项目名片（必问）

1. **启用模块**：
   - `A`（推荐）：完整闭环（飞书研发过程管理 + 单源 VitePress 文档站与教程工坊）
   - `B`：仅飞书研发过程管理（任务清单 + 多维表格 + HTML5 总览 + 交付通知）
   - `C`：仅单源文档站与教程工坊（VitePress + 写作模板 + 质量门禁 + 自动页面截图标注）
2. **项目名称与编号前缀**：例如项目名 `Atlas Engine`，任务编号前缀 `ATL`（滚动小修自动编号为 `ATL-00`）。
3. **Skill 安装位置**：安装在当前仓库内（`.agents/skills/` + `.claude/skills/`，随团队共享）还是本机全局（`~/.agents/skills/`，所有仓库复用）？

## 第二组：飞书过程管理配置（启用 A/B 时问）

4. **飞书 CLI Profile**：要使用的 `lark-cli` profile 名称（留空则使用默认 profile）。
5. **新建还是接入已有**：
   - 一键创建全新的任务清单、多维表格、看板/甘特视图与汇总页；
   - 或接入已有资源（请提供 `tasklist_guid`、`base_token`、`table_id`、`document_id`）。
6. **领域分类（Sections）与项目阶段（Stages）**：
   - 默认领域：`架构与内核`、`核心业务`、`接口与工具`、`验证与发布`（可按项目自定义 3–7 个）
   - 默认阶段：`阶段一·基线与架构`、`阶段二·核心能力`、`阶段三·集成与验收`、`日常·滚动维护`
7. **归档位置与通知群（均可选）**：
   - 飞书知识空间 `space_id` 与父节点 `node_token`（用于把汇总页和任务主文档归入指定知识库；留空则建在个人云空间）
   - 交付通知群 `chat_id`（`oc_...`，需确保对应 Bot 已进群；留空则暂不启用群通知）

## 第三组：文档站配置（启用 A/C 时问）

8. **语言模式**：仅中文（轻量上手）还是中英双语（自动校验双语结构、修订号与显式锚点 `{#id}` 一致）？
9. **访问路径前缀与部署方式**：默认 `/docs/`（GitHub Pages 子路径项目可设为 `/<repo>/`）。
10. **是否启用声明式截图标注**：若项目有 Web UI 需要自动截图标注，提供开发服务默认地址（如 `http://127.0.0.1:5173`）与前端静态目录（可选）。
